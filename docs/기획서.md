## 한 줄 컨셉

저주받은 숲의 심층으로 내려가는 **로그라이트 액션 RPG** — 숲은 깊어질수록, 그리고 머무를수록 강해지며, 플레이어의 욕심을 시험한다.

## 스토리

*(2026-07-28 전면 개편 — 이전 판 "야영지의 마지막 모험가가 봉인의 탑으로 내려간다"는 폐기. 상세는 `상세기획서.md` §3)*

마을로 **물자를 나르던 평범한 모험가**가 숲길에 텐트를 치고 잠든 사이, **검은 안개**가 주위를 에워싸고 뒤틀린 것들이 걸어 나온다. 돌아나갈 수 없다. 그때 땅이 갈라지며 **거대한 뿌리가 하늘로 솟아오른다.**

도착한 마을은 **수십 년째 폐허**다 — 오늘 아침 출발했는데. 뿌리가 뽑혀 나온 땅의 상처로 내려가면 상대가 짐승에서 **사람이었던 것**으로 바뀐다. 마을 사람들은 도망친 게 아니라 아래로 끌려 내려온 것이다.

가장 깊은 곳의 **나무 정령**은 오랫동안 마을을 지켜 온 **수호자**였고, 힘을 잃으면서 오히려 마을을 해치게 되었다. 검은 안개는 그것이 버티지 못하고 흘리는 것이다. 쓰러뜨리는 게 아니라 **놓아주고**, 주인공이 **그 자리에 대신 앉는다.**

- **안개는 나를 죽이지 않는다 — 숲을 다시 세울 뿐이다.** 장소는 되돌아가고 나는 안 되돌아간다. 한 번도 같게 세우지 못하므로 **절차 생성이 곧 설정**
- **첫 플레이는 첫 루프가 아니다.** 텐트 옆에 이미 무덤이 4개 서 있고, 길에 흩어진 기억은 내가 흘린 것이다
- **선대 정령이 후계자를 부른다.** 죽지도 나가지도 못하게 붙잡아 두는 것이 곧 단련이다
- **세대가 바뀐다** — 하드 N단계의 보스는 하드 N−1단계의 주인공이다 (6세대분)

## 코어 루프

```
캠프(텐트) → 안개 벽 앞에서 난이도 선택 → 갈림길 카드 선택(보상+계약) → 장(챕터) 공략
  → [욕심: 보물방·엘리트·회복샘 vs 속도: 바로 출구] → 휴식층 → … → 마지막 장 보스
  → 해방(엔딩) / 사망(캠프로 귀환, 기억 유지·레벨 30%/선택 장비 최대 1개 유지)
```

## 핵심 규칙

- **골드 = 유일한 재화 (경험치 폐지)**: 몬스터를 잡으면 골드가 나오고, **그 골드로 레벨을 올린다**(소울라이크식). 골드는 **레벨업 · 장비 강화 · 포션**으로 갈라지며, 어디에 써도 위험이 따른다.
- **화톳불**: 던전 곳곳(층당 2개)의 **성장 지점**. 골드로 레벨을 올린다 — **한 번 쓰면 불이 꺼진다.** *"지금 올릴까, 아껴서 더 내려갈까."* 레벨업 1회 = **체력 +8 · 공격 +5 · 방어 +5 자동** (포인트 분배 없음), 최대 체력이 오르면 **체력바 자체가 길어진다.**
- **죽음 규칙 (핵심)**: 사망 시 캠프로 귀환.
  **골드 전부 소실** · **레벨 30%만 계승**(10레벨 사망 → 3레벨 시작) · **장비는 최대 하나를 선택해 유지**(선택 없이 진행 가능, 나머지 소실) · **보유한 기억(콤보)과 장착 순서 유지** · 층수·저주 초기화.
  무료 시작 단검과 포션·재료 같은 소모품은 유지 선택에서 제외한다. 다음 런에는 **약한 기본 단검(공격 10)** 을 선택 장비와 별도로 항상 지급해, 빈손 때문에 기억을 사용할 수 없는 상황을 막는다.
  → *"모아두면 전부 잃는다. 살아서 돌아와, 몸에 새겨라."*
- **왜 30% 계승인가**: 시작 레벨이 **저절로 한 점(약 3)으로 수렴**해, 반복해도 **초반 층이 무의미해지지 않는다.** 영구 성장은 문턱을 낮출 뿐, **클리어를 대신하지 않는다** — B9를 뚫는 힘은 이번 런의 **기억(콤보)**이다.
- **승리 조건**: 최심부 **9장**(내부 층 값 B9)의 보스 처치 → 엔딩 시네마틱.
- **계약 카드**: 갈림길 카드에 보상과 페널티가 세트로 붙는다. 예: "지름길 — 기억 2개 획득, 단 몬스터 공격력 +30%".
- **욕심 vs 속도**: 시간이 지날수록 저주(몬스터 강화)가 누적된다(기존 DifficultyManager). 각 층의 선택 요소(보물방·엘리트·회복샘)를 노릴수록 위험해진다.
- **챕터 구성 (하나의 이야기를 나눈 「장」)**: 1~3장 물든 숲(숲 개활지) → 4~6장 삼켜진 마을(폐허 마을·**여울목**·미로) → 7~9장 뿌리 아래(BSP 던전·원형 미로), 9장 = 마지막 장(보스). 사이에 휴식층(RestRoom). 상세는 `상세기획서.md` 참고.
  - 내려갈수록 뒤틀린 것이 **짐승 → 사람이었던 것**으로 바뀐다. 표기는 `B4`·`지하 4층`이 아니라 **`4장`** *(구현 필요 — `FloorManager`)*

## 차별화 포인트 (스트레치 골 포함)

1. **기억(콤보) 조립 — 핵심 차별점**: 공격 모션 하나하나가 "기억"이라는 수집 아이템이다. 획득한 기억을 **원하는 순서로 슬롯에 배치하면 그 순서가 곧 내 콤보 체인**이 된다(드래그앤드롭). 중복 획득 시 중첩 강화 — 매 런 다른 전투 빌드. *(구현됨)*
2. **유령 시스템**: 이전 런에서 죽은 자리에 유품이 남고, 주우면 그 런의 콤보 1개를 획득한다. *(구현됨)*
3. **변칙층**: 미로 씬을 활용한 탈출층(전투 없이 저주 안개를 피해 출구 탐색). *(여유 시)*

## 시연 시나리오 (10분)

캠프에서 시작(앉기→기상 연출) → 난이도 선택 → 지상 숲 진입 → 계약 카드에서 위험한 길 선택 → 한 장에서 보물방 vs 출구 갈등 연출 → **모은 골드로 레벨업 vs 무기 강화 고민** → 사망 → **장비 최대 하나 선택/미선택 화면** → 캠프 귀환(골드 0·레벨 30% 계승·시작 단검 재지급·기억 순서 유지 보여주기) → 개발자 치트로 9장 점프 → 보스전 → 엔딩.

## 스코프 컷 원칙

밀리면 아래부터 자른다: 변칙층 → 미니보스 → 저주 무기 → 범람 확장 연출 → 계약 카드 추가 다양성(핵심 2종은 유지) → **보스와 죽음 규칙은 절대 안 자름** (이 둘이 없으면 게임이 완성돼 보이지 않는다).
