# 보스 구현 프롬프트 — "잠들지 않는 뿌리" (반고정형 나무 정령)

| 항목 | 내용 |
|---|---|
| 최종 갱신 | 2026-07-31 |
| 설계 | 확정 |
| 비주얼 레퍼런스 | 확보 |
| 3D 모델·리깅 | **미제작** |
| 인게임 구현 | 모델 제작 후 착수 |

Unity 6 (URP) 3D 로그라이트 액션 RPG의 최종 보스(9장, 내부 층 값 B9)를 구현한다.
보스 모델은 아직 프로젝트에 없다. 확보한 나무 정령/트렌트 레퍼런스를 기준으로 직접 모델링·리깅한 뒤 아래 설계를 적용한다.

## 컨텍스트 — 이 게임의 핵심 전투 시스템

- **⭐흐름(Flow) 시스템**: 콤보를 이어갈수록 데미지 배율이 누적된다(×1.0→×1.8). 무게(가벼움/보통/무거움)와 연계 태그(상승/돌진/마무리)가 순서를 퍼즐로 만든다. `PlayerFlow`가 배율을 담당.
- **회피 캔슬**: 공격 도중 회피로 빠져나와도 흐름이 유지된다(회피 중 유지 타이머 정지). 단, 맞으면 흐름은 흩어진다.
- **슈퍼아머**: 적은 3히트 후 경직을 무시한다. `EnemyAttribute`에 `HitCount`·`IsSuperArmorImminent`·`OnSuperArmorChanged` 노출됨. 2히트째 노란 점멸, 3히트째 푸른빛 경고(`SuperArmorWarning`).
- 플레이어는 근접 중심(단검/장검/대검), 락온(Q) 있음. 단, **락온 후 스트레이프 이동은 보스 플레이테스트 전에 수정**한다.

## 보스 이동 방식 = 반고정형 [확정]

완전히 못 박힌 게 아니라:
- 한 자리에 뿌리내리되 **플레이어 쪽으로 회전(Turn)**한다.
- 페이즈 전환 시 **`Underground` → `Spawn` 애니메이션으로 순간이동**해 자리를 옮긴다(구도 환기).
- 이유: 플레이어가 안정적으로 붙어 흐름을 쌓되, 보스의 광역·원거리 패턴을 회피로 피하는 리듬을 만든다. 흐름 시스템과 나무 정령 컨셉 둘 다 부합.

## 3페이즈 (HP 임계값 전환)

| 페이즈 | HP | 패턴 | 노림수 |
|---|---|---|---|
| 1 | 100~66% | 느린 후려치기 (Punch / Slash / Smack) | 붙어서 흐름 쌓기 학습 |
| 2 | 66~33% | + 원거리 투사체 (Projectile) | 거리·회피 관리 |
| 3 | 33~0% | + 광역 뿌리 강타 (Step / Swing) · 슈퍼아머 강화 | 회피 캔슬로 빠졌다 마무리 압박 |

## 애니메이션 매핑 (트렌트 클립 기준)

`Idle` · `Punch/Slash/Smack/Step/Swing Attack` · `Projectile Attack` · `Cast Spell`(페이즈 전환 연출) · `Underground`+`Spawn`(순간이동) · `Take Damage` · `Die` · `Turn Left/Right`

## 만들 것

1. **3D 모델·리깅** — 반고정형 실루엣, 회전, 지하 이동, 코어 노출에 필요한 본과 분리 구조를 준비.
2. **`BossController.cs`** (신규) — HP 임계값으로 페이즈 전환, 페이즈별 패턴 풀에서 공격 선택, 회전·순간이동 제어. 체력·슈퍼아머·골드·사망은 기존 `EnemyAttribute`를 재사용.
3. **보스 전용 애니메이터 컨트롤러** — 위 클립 또는 직접 제작한 동등 클립을 상태·전이·파라미터로 연결.
4. **보스 체력바 UI** — 화면 상단 대형 게이지 (일반 적 HP바와 별개).
5. **`BossRoom` 씬에 배치** + 승리 지점을 "보스 처치 시"로 연결(현재는 도달만 하면 승리 → `VictoryZone`을 보스 사망 이벤트로 전환).

## 제약 (CLAUDE.md 규칙)

- 기존 적 시스템(`EnemyAttribute`, FSM, 히트박스, `SuperArmorWarning`)을 최대한 재사용한다.
- 데이터(HP·데미지·페이즈 임계값·패턴 확률)는 하드코딩하지 말고 SerializeField/ScriptableObject로 분리한다.
- 여러 파일을 건드리는 큰 작업이므로, 먼저 범위를 설명하고 확인받은 뒤 진행한다.
- 페이즈·패턴 수치는 일단 위 표대로 넣고 플레이테스트로 조정.
