- Q 락온과 기억 돌진 대상을 일치시키고, 락온 중 카메라/방향 회피를 개선했다. 9월 7일에는 대상 기준 스트레이프와 2D 이동 블렌드를 적용하고 실제 프리팹 및 플레이 모드 재생값을 검증했다.
- 아레나 F2 몬스터 시험장, F3 장비 드랍 패널과 패널 중 카메라 입력 차단을 추가했다.
- 장비 드랍을 3D 모델 중심으로 개편하고 등급별 지면 VFX·빛·나선 레이어를 적용했다.
- 15개 물리 무기의 손잡이 위치와 칼날 방향을 점검했다. `GSOneHand_T1`, `GSGreat_T3`, `GoldSword`의 뒤집힘을 보정했고 황금 장식검의 파지 위치를 손잡이 중앙으로 옮겼다.
- 무기 루트에 기본 그립과 기억별 그립을 합성해 메시·히트박스·트레일이 함께 움직이도록 했다.
- 캐릭터 관리와 기억 구성 화면을 1920×1080 공통 관리 창으로 통합하고, 왼쪽 탭으로 전환하게 했다.
- 인벤토리↔장비 슬롯 드래그 장착/해제, 슬롯 클릭 상세 정보, 버튼 호버 확대와 패널 입력 차단을 연결했다.
- 커스터마이징을 왼쪽 부위 선택·오른쪽 파츠 그리드/색상 선택 구조로 바꾸고 기본 외형은 장비 미착용 상태로 시작하게 했다.
- 난이도 선택, 일시정지/옵션, 장비 해금, 화톳불 성장, HUD, 미니맵/전체 지도, 사망 결과·장비 유지 화면을 같은 나무 프레임 테마로 정리했다.
- HP·포션·골드·정수 표시의 배경과 아이콘 정렬을 보완하고, 빅맵은 `M`키·Fog of War 흐름을 유지하도록 개편했다.
- 사망 후 메인 캠프로 돌아왔을 때 캠프 카메라가 복구되고, 커스터마이징을 다시 열어도 캐릭터 전용 미리보기 카메라가 정상 재연결되도록 수정했다.
- 커스터마이징 미리보기는 `CustomizationPreview` 전용 레이어로 캐릭터 렌더러만 분리해 월드 오브젝트가 가리는 문제를 막았다.

## 지금 가장 중요한 순서

이번 맵 안정화의 바로 다음 작업은 시드 `777`에서 확인한 **이동 후 프롭 끼임 2개체**의 순찰 경로/회피·복구 보완이다. 문틀은 아닌 `Tombs/Bone_02`, `Library/Box_01·Table_01`과 충돌한다. 아래는 프로젝트 전체 우선순위다.

1. **스토리 인게임 반영 5종** — 챕터 표기, 캠프 무덤, 기록자 동물, 튜토리얼 문구, 캠프 출구/7장 뿌리.
2. **보스 최종 밸런스·엔딩 연결** — 모델·리그·3페이즈와 승리 출구는 구현됐다. 장비/락온/회피/카메라 전투 QA, 숲 정화·계승·크레딧을 이어간다.
3. **전체 UI/런 회귀 테스트** — 수정된 락온 이동을 전투에서 확인하고 1920×1080·다른 16:9 해상도, 카메라 가림, 패널 겹침, 마우스/키보드 입력, 사망 2회차, 기억 순서, 포션, 몬스터 애니메이션, 발소리, 드랍 VFX/확률을 한 번에 검증.
4. **배포 전 안전장치** — 생성 시드 기록, 스폰→출구 경로 검증, 세이브 버전 마이그레이션.
5. **폴리싱** — 기억 아이콘, 실제 사운드 교체/믹싱, PushDoor 경고 제거, 화톳불 리스킨.

## 완료 판단 기준

프로젝트를 “핵심 완성”으로 판단하려면 아래가 모두 충족되어야 한다.

- 새 게임 → 계약 선택 → 전투 → 사망 → 장비 선택/미선택 → 다음 런 → 9장 보스 → 엔딩이 끊김 없이 이어진다.
- 사망 2회차에도 장비 인식, 기억 순서, 조작 상태, 포션 입력이 유지된다.
- 보스전에서 Q 락온·방향 회피·기억 돌진·흐름·슈퍼아머가 함께 정상 동작한다.
- 일반/레어/에픽/유니크/레전더리 드랍이 모델을 가리지 않고 즉시 구분된다.
- 캐릭터 관리·기억 구성·커스터마이징·옵션·난이도·화톳불·지도·사망 UI에서 글·슬롯·프레임이 겹치지 않고 마우스/키보드 포커스가 올바르게 전환된다.
- 사망 후 캠프 카메라와 커스터마이징 캐릭터 미리보기가 연속 두 번 정상 복구된다.
- Windows 빌드에서 오류 로그 없이 20~30분 전체 런을 2회 완료한다.
