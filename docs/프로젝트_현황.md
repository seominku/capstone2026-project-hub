## 에셋 교체 현황

Unity `Assets/Editor/AssetChecklist/AssetSwapChecklist.asset`을 현재 프로젝트 구조와 다시 대조했다. 기존 UI·사운드 폴더뿐 아니라 실제 사용 중인 기억 아이콘, 대표 장비 아이콘, 현재 맵 목록, 코드 합성 사운드, 스토리 필수 모델까지 추적한다.

| 구분 | 전체 | 교체 대기 | 신규 제작 | 완료 |
|---|---:|---:|---:|---:|
| UI | 73 | 65 | 8 | 0 |
| 사운드 | 50 | 38 | 12 | 0 |
| 모델 | 5 | 0 | 5 | 0 |
| **합계** | **128** | **103** | **25** | **0** |

가장 먼저 필요한 것은 6개 맵 미리보기, 신규 기억 12종의 전용 아이콘, 보스·캠프 무덤·기록자 동물·뿌리 통로 모델이다. 사운드는 현재 코드 합성으로 동작하는 앰비언스와 심장박동을 최종 음원으로 순차 교체한다. 전체 세부 목록은 `에셋_교체_체크리스트.md`를 기준으로 관리한다.

## 최근 완료된 작업

- 사망 뒤 장비를 다시 들어도 기본 `SmallAttack`으로 떨어지지 않고 저장된 기억 순서대로 콤보가 실행되도록 동기화했다.
- 사망 장비 선택에서 무료 시작 단검과 포션·재료를 제외하고, **아무것도 지키지 않기** 경로를 추가했다.
- 포션 F 입력을 Input System과 직접 키보드 입력 양쪽에서 받을 수 있게 했다.
- 계약 효과의 미연결 소비 지점을 연결하고 런 초기화 규칙을 정리했다.
- Q 락온과 기억 돌진 대상을 일치시키고, 락온 중 카메라/방향 회피를 개선했다. 락온 후 스트레이프 이동은 별도 수정 항목으로 남겼다.
- 아레나 F2 몬스터 시험장, F3 장비 드랍 패널과 패널 중 카메라 입력 차단을 추가했다.
- 장비 드랍을 3D 모델 중심으로 개편하고 등급별 지면 VFX·빛·나선 레이어를 적용했다.
- 15개 물리 무기의 손잡이 위치와 칼날 방향을 점검했다. `GSOneHand_T1`, `GSGreat_T3`, `GoldSword`의 뒤집힘을 보정했고 황금 장식검의 파지 위치를 손잡이 중앙으로 옮겼다.
- 무기 루트에 기본 그립과 기억별 그립을 합성해 메시·히트박스·트레일이 함께 움직이도록 했다.

## 지금 가장 중요한 순서

1. **스토리 인게임 반영 5종** — 챕터 표기, 캠프 무덤, 기록자 동물, 튜토리얼 문구, 캠프 출구/7장 뿌리.
2. **보스 제작 착수** — 레퍼런스 기준 모델 제작 → 리깅/애니메이션 → 3페이즈 컨트롤러 → 승리/엔딩 연결.
3. **락온 스트레이프 수정 + 회귀 테스트** — 좌우·후방 이동 방향/애니메이션을 바로잡고 사망 2회차, 기억 순서, 포션, 몬스터 애니메이션, 발소리, 드랍 VFX/확률을 한 번에 검증.
4. **배포 전 안전장치** — 생성 시드 기록, 스폰→출구 경로 검증, 세이브 버전 마이그레이션.
5. **에셋 교체·폴리싱** — 신규 제작 25개를 먼저 확보한 뒤 교체 대기 103개를 UI·사운드 순으로 교체하고, 화톳불 리스킨을 마무리한다.

## 완료 판단 기준

프로젝트를 “핵심 완성”으로 판단하려면 아래가 모두 충족되어야 한다.

- 새 게임 → 계약 선택 → 전투 → 사망 → 장비 선택/미선택 → 다음 런 → 9장 보스 → 엔딩이 끊김 없이 이어진다.
- 사망 2회차에도 장비 인식, 기억 순서, 조작 상태, 포션 입력이 유지된다.
- 보스전에서 Q 락온·방향 회피·기억 돌진·흐름·슈퍼아머가 함께 정상 동작한다.
- 일반/레어/에픽/유니크/레전더리 드랍이 모델을 가리지 않고 즉시 구분된다.
- Windows 빌드에서 오류 로그 없이 20~30분 전체 런을 2회 완료한다.
