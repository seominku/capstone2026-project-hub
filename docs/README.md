## 먼저 볼 문서

1. [`프로젝트_현황.md`](프로젝트_현황.md) — 현재 완성도, 진행 중인 일, 위험 요소를 한 화면에 본다.
2. [`개발_체크리스트.md`](개발_체크리스트.md) — 다음 작업과 완료 조건을 확인한다.
3. [`변경이력.md`](변경이력.md) — 최근 무엇을 왜 바꿨는지 확인한다.
4. [`기획서.md`](기획서.md) — 게임의 한 줄 컨셉과 핵심 규칙을 빠르게 읽는다.
5. [`상세기획서.md`](상세기획서.md) — 전체 시스템과 콘텐츠 구성을 확인한다.
