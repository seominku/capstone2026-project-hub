## 1. 개요

**목적**
로그라이트의 핵심 계약을 코드로 못박는다 — **무엇이 남고 무엇이 사라지는가.** 이 경계가 흐리면 죽음이 무섭지도, 성장이 기쁘지도 않다.

**핵심 경험**
> *"모아두면 전부 잃는다. 살아서 돌아와, 몸에 새겨라."*

죽으면 골드는 **전부** 사라지고 레벨은 **30%만** 남는다. 장비는 **최대 하나**를 지킬 수 있고, 아무것도 선택하지 않을 수도 있다. 무료 시작 단검은 유지 후보와 무관하게 다음 런에 다시 지급된다.

---

## 2. 범위

**포함**
- JSON 단일 슬롯 저장/로드, 저장 항목 정의
- 사망 시퀀스 전체 (연출 → 결과창 → 장비 선택 → 패널티 → 초기화 → 귀환 → 부활)
- 유지/초기화 분기표
- 유령(유품) 기록

**제외 (이번 범위 아님)**
- 다중 슬롯 · 클라우드 동기화
- 세이브 **버전 마이그레이션** — `Version` 필드는 있으나 **읽지 않는다**. 구조가 바뀌면 기존 세이브는 조용히 기본값으로 대체된다 → §8 미결
- 체크포인트(런 도중 저장) — 저장 시점은 사망·승리·유품 회수뿐이다
- 옵션 설정 저장 (카메라 셰이크 등은 `PlayerPrefs` 별도 관리)

## 3. 동작 흐름

### 3-1. 저장 / 불러오기

```
[Awake] _Path = persistentDataPath/save.json → Load()
Load()  파일 없음 → 새 SaveData()
        파일 있음 → JsonUtility.FromJson (실패 시 catch → 새 SaveData)
        → OnLoaded / OnGoldChanged / OnEssenceChanged 발행
Save()  SavedAt 기록 → JsonUtility.ToJson(pretty) → File.WriteAllText (실패 시 로그만)
```

**저장 시점** — 자동 저장은 없다. 명시적으로 `CaptureAndSave()`가 불릴 때만 쓴다.

| 시점 | 호출 위치 |
|---|---|
| 사망 처리 완료 | `PlayerDeath.DeathRoutine()` |
| 승리(보스 클리어) | `VictoryZone.WinRoutine()` — 하드였다면 `MarkHardTierCleared()` 먼저 |
| 유품 회수 | `GhostRelic` — `Ghost.Exists = false` 후 저장 |

### 3-2. 사망 시퀀스

| # | 단계 | 내용 |
|---|---|---|
| 0 | 진입 가드 | `_IsDying`이면 무시 (중복 방지) |
| 1 | **콤보 상태 정리** | `PlayerCombat.CancelCombo()` — 공격 중 사망 시 `PlayerStat`(SO)이 ATTACK에 멈춰 **다음 런에서 못 움직이는 버그**가 있었다 |
| 2 | 조작 차단 | `PlayerInput` + 6개 컴포넌트 비활성 |
| 3 | 상체 레이어 0 | 전투·소모품 레이어가 사망 모션을 덮어써서 안 보이던 문제 |
| 4 | `Die` 트리거 | **파라미터 존재 확인 후** 발동 (캠프 앉기 컨트롤러엔 없음 → 에러 로그 방지) |
| 5 | 대기 | `_DeathAnimDuration` = **2.8초** *(클립 길이 2.3초 + 여유)* |
| 6 | 결과창 | `DeathScreenPanel` — 플레이 타임·도달 층·처치 수·입힌 데미지 |
| 7 | **장비 최대 1개 선택** | `DeathChoicePanel` — 장착 + 인벤토리의 장비 중 하나 또는 **[아무것도 지키지 않기]**. 무료 단검·포션·재료 제외 |
| 8 | `KeepOnly(kept)` | 전 슬롯 해제 + 인벤토리 비움 → **무료 시작 단검 재지급** → 선택 장비가 있으면 인벤토리에 넣음(착용 아님) |
| 9 | 유령 기록 | 0층(캠프)이면 **기록 안 함** |
| 10 | 패널티 | `ApplyDeathPenalty()` + `LoseAllGold()` |
| 11 | 저장 | `RecordDeath()` → `CaptureAndSave()` |
| 12 | 런 초기화 | Trait · Contract · Reward · Floor(0) · Difficulty |
| 13 | 페이드 → 귀환 | `ForestPath` 로드 |
| 14 | 부활 | 씬 로드 감지 → `ReviveFull()` · 트리거 리셋 · `Animator.Rebind()` · **조작은 켜지 않음** (캠프는 앉은 상태, `ForestGameFlow`가 담당) |

**상태 전이**

| 현재 상태 | 입력/조건 | 다음 상태 | 비고 |
|---|---|---|---|
| 생존 | HP ≤ 0 | 사망 연출 | `Attribute.Die()` → `OnDied` |
| 사망 연출 | 중복 `OnDied` | 무시 | `_IsDying` 가드 |
| 사망 연출 | 2.8초 경과 | 결과창 | |
| 결과창 | [메뉴로] | 장비 선택 | |
| 장비 선택 | 장비 선택 / **아무것도 지키지 않기** / 시간 초과 | 패널티 적용 | 미선택 버튼은 선택 장비 없음, 시간 초과는 최강 장비 자동 선택 |
| 패널티 | 저장 완료 | 캠프 로드 | |
| 캠프 로드 | `sceneLoaded == ForestPath` **and** `_IsDying` | 부활 | 한 프레임 대기 후 |
| 부활 | 완료 | 생존(앉음) | `_IsDying = false` |

### 3-3. 유지 / 초기화 분기 **(핵심 표)**

| 대상 | 사망 시 | 근거 |
|---|---|---|
| **골드** | **전부 소실** | 유일한 성장 재화 — 쌓아두는 플레이를 막는다 |
| **레벨** | **30%만 계승** (최소 1) | 시작 레벨이 한 점(≈3)으로 수렴 → 반복해도 초반 챕터가 무의미해지지 않는다 |
| 스탯(체력·공격·방어) | 레벨과 함께 감소 | 스탯은 레벨로만 결정 (포인트 분배 폐지) |
| **장비** | **선택한 최대 1개 유지**, 인벤토리에 보관. 선택 없이 진행 가능 | 강화 수치 포함 |
| **무료 시작 단검** | 유지 선택에서 제외, 인벤토리에 재지급 | 공격력 10. 기억 공격을 쓸 최소 무기 보장 |
| 인벤토리의 포션·재료 | 전부 소실, 유지 선택에서 제외 | 소모품을 장비 대신 보존할 수 없음 |
| **숲의 정수** | **유지** | 메타 재화 — 장비 해금용 |
| 해금 목록 | 유지 | |
| 포션 강화 레벨 | 유지 | |
| 하드 클리어 단계 | 유지 | |
| 보유한 기억(콤보)과 장착 순서 | **유지** | 다음 판 시작 시 `RewardManager`에서 `PlayerCombat`으로 재동기화 |
| 챕터 · 저주 · 특성 · 계약 | **초기화** | 런 한정 |
| 사망 횟수 | +1 | 캠프 묘비에 반영 |
| 유령(유품) | 죽은 자리에 **1개** 기록 | 캠프 사망은 제외 |

> **승리 시에는** `VictoryZone`이 `RewardManager.ResetRun()`을 호출해 기억까지 초기화한다. 사망 귀환과 달리 완전히 새 조합으로 시작한다.

## 4. 데이터 정의

**`SaveData`** (JSON 단일 슬롯 · `persistentDataPath/save.json`)

| 항목명 | 타입 | 기본값 | 설명 |
|---|---|---|---|
| `Version` | int | 1 | **현재 읽지 않음** → §8 |
| `Level` | int | 1 | 스탯은 여기서 자동 계산 |
| `Gold` | int | 0 | 죽으면 0 |
| `Essence` | int | 0 | 숲의 정수 — 죽어도 유지 |
| `UnlockedItemIds` | List\<int\> | 빈 목록 | 해금 전 장비는 드랍되지 않음 |
| `Weapon`/`Armor`/`Helmet`/`Gloves`/`Pants`/`Boots`/`Belt` | SavedItem | 빈 항목 | `ItemID == 0`이면 빔 |
| `Rings` | List\<SavedItem\> | 빈 목록 | |
| `Inventory` | List\<SavedItem\> | 빈 목록 | |
| `DeathCount` | int | 0 | 묘비 개수 |
| `HasSeenIntro` | bool | false | 2회차부터 짧은 기상 연출 |
| `HasSeenTutorial` | bool | false | 온보딩 1회만 |
| `PotionLevel` | int | 0 (0~5) | 강화당 회복량 +5%p |
| `HardTierCleared` | int | 0 (0~6) | 깨면 다음 단계 해금 |
| `Ghost` | GhostData | — | 마지막 사망 흔적 |
| `SavedAt` | string | "" | 표시용 |

**`SavedItem`** — 드랍 장비는 `RollStats()`로 수치가 랜덤 롤된 복사본이라 **ID만으로 복원 불가.** 롤 결과를 함께 저장한다.

| 항목명 | 타입 | 설명 |
|---|---|---|
| `ItemID` / `Grade` / `Count` | int | 등급은 원본과 달라질 수 있어 별도 저장 |
| `Damage` / `Defence` / `BonusHp` / `BonusDamage` | float | 해당 없는 타입은 0 |
| `EnhanceLevel` | int | 지킨 장비는 강화가 유지된다 (상한은 등급이 결정) |
| `AffixTypes` / `AffixValues` | List\<int\> / List\<float\> | **병렬 배열** — 인덱스 대응 |
| `UniqueEffect` | int | 전설 고유 효과, 0 = 없음 |

**`GhostData`** — `Exists` / `Floor` / `Scene` / `X,Y,Z` / `ComboName`(원본 에셋 이름)

**성장 수치** — `PlayerStat` (ScriptableObject)

| 항목명 | 타입 | 기본값 | 설명 |
|---|---|---|---|
| `LevelCarryOverRate` | float | **0.3** (0~1) | 죽으면 이 비율만 남음. 최소 1레벨 |
| `BaseLevelUpCost` | int | 100 | 레벨업 골드 비용 |
| `CostGrowthRate` | float | 1.25 | 비용 = `Base × Rate^(레벨-1)` |
| `HpPerLevel` | float | 8 | 레벨업당 최대 체력 |
| `DamagePerLevel` | float | 5 | 레벨업당 공격력 |
| `DefencePerLevel` | float | 5 | 레벨업당 방어력 |

**검증 케이스**: Lv10 · 2100G 사망 → **Lv3 · 골드 0**

## 5. 예외 처리

| 상황 | 처리 | 피드백 |
|---|---|---|
| 세이브 파일 없음 | 새 `SaveData()`로 시작 | 없음 (정상 경로) |
| **세이브 파일 손상** | `catch` → 새 `SaveData()`로 시작. **게임은 멈추지 않는다** | `Debug.LogError` |
| `FromJson` 결과 null | `?? new SaveData()` | 없음 |
| 저장 실패(권한·디스크) | 로그만 남기고 진행 | `Debug.LogError` |
| **세이브 구조 변경** | 없는 필드는 기본값, 남는 필드는 무시 → **조용한 데이터 손실** ⚠️ | 없음 → §8 |
| 사망 중 재차 사망 | `_IsDying` 가드로 무시 | 없음 |
| `Die` 애니메이터 파라미터 없음 | 트리거 생략, 시퀀스는 계속 | 없음 |
| **[아무것도 지키지 않기]** | `kept == null` → 선택 장비 없이 진행, 무료 단검만 재지급 | 명시적 버튼 |
| 지킬 후보 장비가 없음 | 선택 화면 생략 → 무료 단검만 재지급 | |
| 무기 해제로 빈손 | `EquipmentSystem` 기본 무기 폴백 + 런 시작 시 `StarterLoadout.EnsureDaggerForPlayer()` | |
| `Inventory`가 플레이어에 없음 | `FindFirstObjectByType`로 폴백 | |
| 캠프(0층)에서 사망 | 유령 기록 안 함 | |
| `SaveManager` 없음 | 패널티·저장 전부 건너뜀, 시퀀스는 진행 | 없음 ⚠️ |
| 공격 중 사망 | 1단계에서 콤보 강제 종료 | — |
| 다음 런 무기 장착 후 기본 공격만 실행 | 보유 기억과 장착 순서를 `RewardManager`에서 `PlayerCombat`으로 다시 동기화 | 저장된 순서대로 콤보 실행 |
| **동시 발생 우선순위** | 결과창 → 장비 선택 → 패널티 → 초기화 (**순차 코루틴**이라 경합 없음) | — |

## 6. UI / 연출

| 요소 | 표시 조건 | 갱신 시점 | 연출 |
|---|---|---|---|
| 사망 모션 | HP ≤ 0 | 즉시 | 상체 레이어 0으로 낮춰 Base Layer만 |
| 결과 화면 | 모션 2.8초 후 | 1회 | 화면 위에서 내려옴. 플레이 타임·도달 층·처치 수·데미지 |
| 장비 선택 | 결과창 닫은 뒤 | 1회 | 장비 최대 하나 또는 **[아무것도 지키지 않기]**. 무료 단검·소모품은 표시하지 않음 |
| 화면 페이드 | 선택 후 | 1회 | 검은 페이드 → 캠프 로드 시 자동 해제 |
| 골드 HUD | 상시 | `OnGoldChanged` | 사망 직후 0 |
| 정수 HUD | 상시 | `OnEssenceChanged` | 변화 없음 |
| 캠프 묘비 | 캠프 진입 | `DeathCount` 기준 | 죽을수록 늘어남 |
| 유품 | 다음 런, 같은 씬·같은 자리 | 씬 로드 | 봇짐 + 푸른 흔적 빛 |

## 7. 의존 관계

- **선행 필요**: `Attribute`(플레이어) · `PlayerStat`(SO) · `EquipmentSystem` · `Inventory`
- **참조 시스템**: `TraitManager` · `ContractManager` · `RewardManager` · `FloorManager` · `DifficultyManager` · `RunStats` · `LoadingManager` · `ScreenFader` · `DeathScreenPanel` · `DeathChoicePanel`
- **영향받는 기능**: 캠프 묘비 · 유령 시스템 · 장비 해금(정수) · 하드 단계 해금 · 온보딩(1회만)

## 8. 미결 사항

| 항목 | 내용 | 결정 기한 |
|---|---|---|
| **세이브 버전 마이그레이션** | `Version` 필드가 있는데 로드 시 확인하지 않는다. 구조를 바꾸면 기존 플레이 데이터가 조용히 사라진다 | **빌드 배포 전** |
| `SaveManager` 부재 시 무음 | 패널티가 통째로 스킵되는데 로그가 없다 | 폴리싱 |
| 자동 저장 없음 | 런 도중 강제 종료 시 그 런의 획득분이 전부 사라진다. 의도인지 확인 | 플레이테스트 후 |
| `_ComponentsToDisable` 문자열 배열 | 컴포넌트 이름을 문자열로 지정 — 리팩터링 시 조용히 깨진다 | 리스크 감수 중 |
