## 1. 개요

**목적**
공격 모션("기억")을 슬롯에 배치한 **순서**가 데미지에 직접 반영되게 한다. 순서를 잘못 짜면 배율이 오르지 않아야 **콤보 조립이 퍼즐이 된다.**

**핵심 경험**
> 아무 순서나 꽂으면 안 오른다. **가벼운 것으로 열고, 무거운 것으로 끝낸다.**

배율 계산은 `PlayerFlow`가 **혼자 책임진다** — `PlayerCombat`은 콤보 진행만 담당한다.

## 3. 동작 흐름

### 3-1. 한 타의 처리 순서

```
[입력] 공격 → 슬롯 N번째 기억 선택
   ↓
OnComboUsed(combo)                     ← 스윙 시작. 이 타에 적용할 배율을 확정
   · 유지시간 초과했으면 ResetFlow()
   · 직전 태그가 Rising이면 이번 타에만 ×1.30
   · _PendingCombo에 보관 (아직 안 쌓임)
   ↓
[애니메이션 이벤트] 히트박스 ON → 충돌
   ↓
NotifyHit()                            ← 실제로 맞았을 때만
   · gain = 무게별 상승량
   · gain ×= (1 + 특성 되새김 + 접사 FlowGain)
   · 직전 Rush + 이번 Finisher → gain += 0.20
   · _Multiplier = min(_Multiplier + gain, 1.8)
   · _HitCount++ / _LastTag 갱신 / OnFlowChanged 발행
   · 이번이 Finisher면 → ResetFlow()   ← 쏟아붓고 소멸
```

**최종 데미지 계산식** (`PlayerCombat`)

```
damage = (플레이어 최종 공격력 + 기억 데미지)
       × 흐름 배율        (OnComboUsed 반환값, 1.0 ~ 1.8 [× 1.30 상승보너스])
       × 무기 시너지      (0.85 / 1.0 / 1.20)
       × 특성·접사 보너스  (여운 · FinisherDamage — 마무리 한정)
       × 약화 배수        (저주 '약화의 일격', 없으면 1.0)
```

> **곱셈 순서가 결과를 바꾸지 않도록 전부 곱셈으로만 구성했다.** 덧셈이 섞이면 적용 순서에 따라 값이 달라져 밸런스 추적이 어려워진다.

### 3-2. 상태 전이

| 현재 상태 | 입력/조건 | 다음 상태 | 비고 |
|---|---|---|---|
| 흐름 없음 (×1.0) | 기억 명중 | 흐름 유지 | `_HitCount = 1` |
| 흐름 유지 | 기억 명중 | 흐름 유지 | 배율 누적 (상한 1.8) |
| 흐름 유지 | **허공 스윙** | 흐름 유지 | **아무것도 안 오름** — `_PendingCombo`가 소비되지 않음 |
| 흐름 유지 | **맨손(기본 공격)** | 흐름 없음 | 즉시 `ResetFlow()` — 주먹은 흐름을 끊는다 |
| 흐름 유지 | **마무리(Finisher) 명중** | 흐름 없음 | 배율을 다 쏟은 뒤 소멸 |
| 흐름 유지 | **피격** | 흐름 없음 | 단, 유니크 「불굴」이면 **층당 1회** 버팀 |
| 흐름 유지 | 마지막 명중 후 `HoldTime` 경과 | 흐름 없음 | 기본 1.5초 (+ 접사 `FlowHold`) |
| 흐름 유지 | **회피 중** | 흐름 유지 | `_LastHitTime`을 매 프레임 갱신 → **시간이 흐르지 않는다** |
| 흐름 유지 | 콤보 종료(입력 끊김) | 흐름 유지 | 유지시간 동안은 남는다 |
| 임의 상태 | 사망 | 흐름 없음 | `CancelCombo()` |
| 임의 상태 | 씬 로드 | 흐름 유지 + 불굴 재충전 | `_IndomitableUsed = false` |

### 3-3. 설계 의도 (왜 이렇게 정했는가)

| 규칙 | 이유 |
|---|---|
| **명중해야 쌓인다** | 허공에 휘둘러 배율을 미리 채우는 우회를 막는다 |
| 스윙당 1회만 카운트 | 다단히트 무기가 배율을 몇 배로 쌓는 것을 막는다 (`_PendingCombo = null`) |
| **맨손은 흐름을 끊는다** | 기본 공격으로 배율을 유지하면 "기억을 모을 이유"가 사라진다 |
| 회피 중 시간 정지 | 무거운 기억은 느려서 얻어맞기 쉽다 → 회피로 끊고 다시 이어붙일 수 있어야 **위험한 기억을 넣는 선택**이 성립한다 |
| 피격 시 소멸 | 안 맞고 이어가는 것이 곧 실력 |
| 마무리 후 소멸 | 쌓기 → 터뜨리기의 리듬을 만든다 |
| 상한 1.8 | 무한 누적이면 긴 콤보만 정답이 된다 |

## 4. 데이터 정의

**흐름 파라미터** — `PlayerFlow` (컴포넌트, 인스펙터 노출)

| 항목명 | 타입 | 기본값 | 범위 | 설명 |
|---|---|---|---|---|
| `_MaxMultiplier` | float | **1.8** | 1.0~ | 배율 상한 |
| `_HoldTime` | float | **1.5** | 초 | 마지막 명중 후 흐름 유지 시간 |
| `_LightGain` | float | **0.08** | | 가벼움 1타당 상승 |
| `_NormalGain` | float | **0.14** | | 보통 1타당 상승 |
| `_HeavyGain` | float | **0.25** | | 무거움 1타당 상승 |
| `_AfterRisingBonus` | float | **0.30** | | 상승 직후 타의 **데미지** 배수 (흐름 아님, 그 타에만) |
| `_RushToFinisherGain` | float | **0.20** | | 돌진 → 마무리 연계 시 추가 상승 |

> **상한 도달 타수**: 가벼움만 10타 / 보통만 6타 / 무거움만 4타 (보너스 제외)

**기억 정의** — `AttackCombo` (ScriptableObject)

| 항목명 | 타입 | 기본값 | 설명 |
|---|---|---|---|
| `_AttackClip` | AnimationClip | — | 런타임에 `AnimatorOverrideController`로 교체 |
| `_Damage` | float | — | 기억 자체 데미지 (플레이어 공격력에 **더해진다**) |
| `_Weight` | ComboWeight | Normal | Light / Normal / Heavy |
| `_Tag` | ComboTag | None | None / Rising / Rush / Finisher |
| `_PlaybackSpeed` | float | 0 | **0이면 무게 기본 속도**, 값이 있으면 고정 배속 |
| `_UseRootMotion` | bool | false | |
| `_GripEuler` | Vector3 | (0,0,0) | 그립 보정 — 임포트 팩마다 손목 규약이 달라 칼날이 엉뚱한 축을 향할 때 |
| `_Grade` | ItemGrade | — | 등급 5단계 |
| `_HasElement` / `_Element` | bool / ElementType | false / Fire | 화염·냉기·대지·전격 |
| `_Icon` / `_DisplayName` | Sprite / string | — | 비면 에셋 이름 사용 |

**연계 태그 효과**

| 태그 | UI 표기 | 효과 |
|---|---|---|
| `None` | - | 없음 |
| `Rising` | 상승 | **다음 타**가 공중 판정 — 그 타 데미지 ×1.30 |
| `Rush` | 돌진 | **마무리로 이으면** 흐름 +0.20 |
| `Finisher` | 마무리 | 쌓은 배율을 전부 쏟고 **흐름 소멸** |

**무기 × 기억 시너지** — `WeaponSynergy` (정적 상수)

| 무기 계열 | 선호 무게 | 가벼움 | 보통 | 무거움 |
|---|---|---|---|---|
| **경량**(단검) | Light | **×1.20** | ×1.00 | **×0.85** |
| **표준**(장검) | Normal | ×1.00 | **×1.20** | ×1.00 |
| **중량**(대검) | Heavy | **×0.85** | ×1.00 | **×1.20** |

- `MatchBonus = 1.20` / `MismatchPenalty = 0.85` (정반대 조합만)
- 무기 미장착 시 ×1.0
- **의도**: 무기가 단순 상위호환이 되지 않게 한다. 대검을 들면 가벼운 기억 위주 콤보는 **오히려 약해진다.**

**외부 보정** (다른 시스템이 흐름에 개입하는 지점)

| 출처 | 대상 | 효과 |
|---|---|---|
| 특성 「되새김」 | `TraitEffect.FlowGain` | 흐름 상승량 증가 (곱연산) |
| 접사 `FlowGain` | 동일 | 합산 후 곱연산 |
| 접사 `FlowHold` | `HoldTime` | 유지 시간 **가산** |
| 특성 「여운」 · 접사 `FinisherDamage` | 마무리 데미지 | |
| 유니크 「불굴」 | 피격 시 흐름 유지 | **층당 1회** |
| 저주 「약화의 일격」 | `StatusEffects.DamageMultiplier` | 최종 데미지 감소 |

### 4-1. 무기 그립·트레일 정합 **[2026-07-31 구현]**

| 데이터/함수 | 역할 |
|---|---|
| `WeaponData.GripPosition` | 손 소켓 기준 무기 기본 위치. 피벗이 손잡이 끝에 있는 모델을 보정 |
| `WeaponData.GripEuler` | 무기 자체의 기본 방향. 칼날이 안쪽을 보는 비대칭 모델을 보정 |
| `AttackCombo._GripEuler` | 특정 기억 애니메이션 동안 추가할 손목/무기 회전 |
| `EquipmentSystem.ApplyComboGrip()` | `기본 그립 × 기억 그립`을 쿼터니언 순서로 합성 |
| `EquipmentSystem.ResetWeaponGrip()` | 공격 종료·취소·사망 시 무기 기본 그립으로 복귀 |

무기 프리팹의 루트 전체를 이동·회전한다. 메시만 따로 돌리지 않으므로 **칼날, 히트박스, 트레일이 같은 기준**을 사용한다. 물리 무기 15종을 점검했고 `GSOneHand_T1`, `GSGreat_T3`, `GoldSword`의 방향과 황금 장식검의 파지 위치를 보정했다.

## 5. 예외 처리

| 상황 | 처리 | 피드백 |
|---|---|---|
| `PlayerFlow` 컴포넌트 없음 | `PlayerCombat.Awake()`가 **자동으로 추가** — 없어도 배율 1.0으로 굴러감 | 없음 |
| `combo == null` | `OnComboUsed`가 현재 배율 그대로 반환 | 없음 |
| `NotifyHit`인데 `_PendingCombo == null` | **무시** — 다단히트 2번째 이후 | 없음 |
| 허공 스윙 | 흐름 변화 없음. `_PendingCombo`는 다음 `OnComboUsed`에서 덮어써짐 | 없음 |
| 유지시간 초과 후 첫 타 | `OnComboUsed` 진입 즉시 `ResetFlow()` → 1.0부터 다시 | HUD 0으로 |
| 회피 중 유지시간 만료 | **만료되지 않음** (`_LastHitTime` 갱신) | |
| 피격 + 불굴 미사용 | 흐름 유지, `_IndomitableUsed = true` | |
| 피격 + 불굴 이미 사용 | `ResetFlow()` | HUD 0으로 |
| 무기 없음 | 시너지 ×1.0 | |
| **공격 도중 사망** | `PlayerDeath`가 `CancelCombo()` 선호출 — 안 하면 `PlayerStat`(SO)이 ATTACK에 멈춰 **다음 런에서 못 움직인다** | — |
| 사망 뒤 무기 재장착 | `RewardManager`의 보유 기억·장착 순서를 `PlayerCombat`에 재동기화 — `SmallAttack` 폴백 방지 | 콤보 슬롯 UI |
| 공격 종료·회피 취소 | `ResetWeaponGrip()`으로 기본 위치·방향 복원 | 트레일과 칼날 일치 |
| `ResetFlow` 중복 호출 | 이미 초기 상태면 이벤트도 발행 안 함 | |
| **동시 발생 우선순위** | 마무리 소멸 > 피격 소멸 > 시간 만료 (모두 `ResetFlow` 수렴이라 결과 동일) | — |

## 7. 의존 관계

- **선행 필요**: `Attribute`(공격력·`OnDamaged`) · `EquipmentSystem`(무기 계열·접사·유니크) · `AnimatorOverrideController` 슬롯 구조
- **참조 시스템**: `TraitManager` · `StatusEffects`(저주) · `PlayerDodge`(회피 중 판정) · `WeaponHitbox`(`NotifyWeaponHit`) · `CombatFeel`
- **영향받는 기능**: 적 슈퍼아머(3히트로 콤보를 끊음 — 흐름 설계의 상대 축) · 콤보 슬롯 해금(레벨) · 기억 제련소
