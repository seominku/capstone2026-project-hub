# 절차적 맵 생성

| 항목 | 내용 |
|---|---|
| 문서 버전 | v1.1 |
| 최종 수정 | 2026-07-31 |
| 상태 | **구현완료** (문서는 현재 코드 기준 역작성) |
| 관련 코드 | `ForestFieldGenerator` · `RiverCrossingGenerator` · `RuinedVillageGenerator` · `Dungeon/BSPDungeonGenerator` · `MazeGenerator` · `CircleMazeGenerator` |

> 가이드 §5가 **1순위**로 지목한 유형 — *파라미터가 많고 결과가 비결정적이라 재현·디버깅이 어렵다.*
> 이 문서의 목적은 **"이 값이 뭘 하는지"** 와 **"왜 이렇게 실패하는지"** 를 남기는 것이다.

---

## 1. 개요

**목적**
매 런 다른 맵을 만들되, **항상 플레이 가능**해야 한다 — 스폰이 허공에 뜨지 않고, 출구까지 길이 있고, 프롭이 지형에 파묻히지 않는다.

**핵심 경험**
같은 맵을 두 번 걷지 않는다. 스토리상으로도 *"안개가 숲을 다시 세우되 한 번도 같게 세우지 못한다"* 로 설명된다.

---

## 2. 범위

**포함**
- 6종 생성기의 공통 파이프라인과 각자의 파라미터
- 지형 높이 결정 방식, 접지(seating) 규칙
- 생성 실패 시 처리, 재현(시드) 정책
- NavMesh 런타임 베이크와의 순서

**제외 (이번 범위 아님)**
- **시드 고정 재현** — 현재 어떤 생성기도 시드를 저장하지 않는다. 버그 재현이 불가능하다 → §8 **최우선 미결**
- 유체 시뮬레이션 내부(SWE) — 별도 문서 필요
- WFC 모듈 규칙표 · 가구 어닐링 비용 함수의 수식
- 맵 아트/프롭 선정

## 3. 동작 흐름

### 3-1. 공통 파이프라인

```
Awake 또는 Start 에서 Generate() 호출
  ①  기존 생성물 제거 (그룹 오브젝트 파괴)
  ②  지형 생성      — 높이 함수 → 메시
  ③  경계 처리      — 나무 띠 / 안개 장막 / 보이지 않는 벽
  ④  주요 구조물    — 굴·다리·계단·광장
  ⑤  산포           — 나무·바위·덤불·풀 (포아송 디스크)
  ⑥  게임플레이 배치 — 스폰·출구·보물상자·회복샘·화톳불
  ⑦  NavMesh 베이크 (런타임)
  ⑧  적 스폰
```

**호출 시점이 생성기마다 다르다** — 이것이 실제 버그 원인이 된 적이 있다.

| 생성기 | 호출 위치 | 이유 |
|---|---|---|
| `ForestFieldGenerator` | **`Awake()`** | `PlayerPersistence`가 씬 로드 직후 `PlayerSpawnPoint`를 찾는다 — `Start`면 늦다 |
| `RiverCrossingGenerator` | **`Awake()`** | 동일 |
| `RuinedVillageGenerator` | **`Awake()`** | 동일 |
| `MazeGenerator` | `Start()` | |
| `CircleMazeGenerator` | `Start()` | |
| `BSPDungeonGenerator` | `Start()` | `generateOnPlay == false`면 에디터에서 구운 것을 그대로 사용 |

> **파생 규칙**: 생성 이후에 씬 전체를 훑는 처리(예: 작은 물체 그림자 컬링)는 **씬 로드 다음 프레임**에 돌아야 한다. `sceneLoaded`는 `Start`보다 먼저 불린다.

### 3-2. 지형 높이 — 「마지막에 판다」 규칙

물이 지나는 곳은 **평탄화가 물길을 도로 메우지 못하도록 맨 마지막에** 깎는다. 셋 다 `Min` 연산이라 겹쳐도 깊은 쪽이 이긴다.

```
높이(x,z) = BaseHeight(펄린 언덕)
          → 평탄화 스팟들(앵커 주변을 중심 높이로 Lerp)
          → RiverCarve(Min)
          → LakeCarve(Min)
          → LinkCarve(Min)
```

> **실패 사례**: 이 순서를 지키지 않았을 때 5m 간격 평탄화 디스크(반경 6.6)가 겹쳐 **폭포 한가운데 초록 지형 쐐기**가 생겼다. 연속 함수 + Min으로 바꿔 해결.

### 3-3. 접지 (Seating) — 프롭이 뜨거나 파묻히지 않게

```
1. 배치 지점의 지면 높이 측정 — 중심 + 네 모서리(발자국)의 최저점
2. 렌더러 전체를 합산한 실측 바운드로 오브젝트 하단을 지면에 맞춤
3. 경사 보정: extraSink = min((최고점 - 최저점) × SlopeSink, 높이 × 0.35)
4. 콜라이더 없는 프리팹에는 메시 콜라이더 자동 추가 (통과 방지)
```

- **바운드 중심이 아니라 피벗 기준**으로 계산하면 어긋난다 — 임포트 팩마다 피벗 위치가 다르다
- 경사면에서 뜨는 것을 막기 위해 **네 모서리 중 가장 낮은 지점** 기준으로 가라앉힌다

### 3-4. 물에 잠기지 않게 (여울목)

```
IsUnderExpectedWater(위치, 여유):
   reach = 강폭/2 + Lerp(8, 26, 하류로 갈수록)      ← 거리에 따라 판정 범위 확대
   물 근처가 아니면 false
   지형높이 < 예상수위(x) + 여유  →  배치 금지
```

- **예상 수위**에는 폭포 뒤 수위 상승(backup) 항이 들어간다 — 실측 기반 경험식
- 이 항이 없으면 폭포 근처에 배치한 것이 나중에 잠긴다

### 3-5. 상태 전이 (생성 결과)

| 현재 상태 | 조건 | 다음 상태 | 비고 |
|---|---|---|---|
| 생성 시작 | — | 지형 완료 | |
| 지형 완료 | 스폰 지점이 지면 메시 밖 | **클램프 후 재배치** | 폐허 마을 `ClampIntoVillage()` |
| 배치 중 | 포아송 최소 간격 위반 | 해당 후보 폐기 | 개수 부족은 허용 |
| 배치 중 | 물 아래 판정 | 해당 후보 폐기 | |
| 구조물 완료 | 다리 통행 검사 실패 | — | **현재 자동 재시도 없음** ⚠️ |
| 전부 완료 | — | NavMesh 베이크 | |
| 베이크 완료 | 경로 없음 | — | **현재 검출하지 않음** ⚠️ |

## 5. 예외 처리

| 상황 | 처리 | 피드백 |
|---|---|---|
| **스폰이 지면 메시 밖** | `ClampIntoVillage()`로 안쪽에 가둠 | 없음 — 20회 재생성 전수 검증(0건) |
| 프롭이 경사면에서 뜸 | 발자국 최저점 + `SlopeSink` 보정 | 없음 |
| 프롭이 물에 잠김 | `IsUnderExpectedWater()`로 배치 거부 | 없음 |
| 콜라이더 없는 프리팹 | 메시 콜라이더 자동 추가 | 없음 |
| 포아송 배치 실패 | 후보 폐기, **개수가 목표보다 적어도 진행** | 없음 |
| 다리 회전 오류 | 스팬 축 자동 판별 + 피벗 오프셋 보정 | 없음 — 과거 111지점 중 46곳 통행 불가였다 |
| 물 평면이 지형에 묻힘 | 구간별 수위 사용 | 과거 14개 중 13개가 묻혔다 |
| **생성 후 경로 없음** | **검출하지 않음** ⚠️ | 없음 → §8 |
| **생성 자체 실패(예외)** | 예외가 `Awake`를 빠져나가면 씬이 반쯤 만들어진 채 진행 | Unity 기본 예외 로그 → §8 |
| NavMesh 베이크 실패 | 적이 제자리에 멈춤 | 없음 ⚠️ |
| 전층 일괄 정적 배칭 | **폐기됨** — 에디터 12GB 프리즈 | — |

## 7. 의존 관계

- **선행 필요**: NavMeshSurface(런타임 베이크) · `Object`/`Environment`/`InteractionLayer` 레이어 · 프리팹 세트
- **참조 시스템**: `PlayerPersistence`(스폰 지점 탐색 — **`Awake` 생성이 필수인 이유**) · `FloorManager` · `NextLevel` · `EliteSpawn` · `FluidSimulator`(여울목) · `SmallObjectShadowCuller`(생성 다음 프레임)
- **영향받는 기능**: 적 AI(NavMesh 없으면 못 움직임) · 미니맵 · 발소리 표면 감지

## 8. 미결 사항

| 항목 | 내용 | 결정 기한 |
|---|---|---|
| **시드 고정·저장 없음** ★ | 어떤 생성기도 시드를 남기지 않아 **버그 재현이 불가능하다.** "가끔 길이 막힌다"를 추적할 방법이 없다. `Random.InitState(seed)` + 세이브/로그 기록 필요 | **플레이테스트 전** |
| **생성 후 경로 검증 없음** | 스폰→출구 도달 가능성을 검사하지 않는다. NavMesh 경로 질의 1회로 확인 가능 | 플레이테스트 전 |
| 생성 실패 시 폴백 없음 | 예외가 나면 반쯤 만들어진 씬으로 진행한다. 재시도 또는 안전 맵 폴백 | 빌드 배포 전 |
| 챕터별 밀도 변주 | 1장 성김 → 3장 빽빽 (기획서 §5 아이디어) | 콘텐츠 확장 |
| `MyMoney` 씬 용도 | 5MB 손제작 실내 레벨이 기획서에 없다. 폐허 마을/던전 배리에이션 재활용 가능성 | 콘텐츠 확장 |
