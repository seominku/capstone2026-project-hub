## 2026-08-10

### 플레이어 공격 템포·참격 VFX

- 기억별 기존 재생 배속을 유지하면서 모든 플레이어 공격의 최종 애니메이션 속도에 공통 `×2`를 적용했다.
- 참격 루트 크기를 `1.7 → 5.1`로 확대하고 위치 `(0, 1.0, 0.9)`, 재생 `0.60초`, 프리웜 풀 3개의 계약을 유지했다.
- FXTags 참고를 바탕으로 무지개 합성 판을 제거하고 Rear·Body·Core·Debris 시트와 짧은 Sparks로 역할을 분리했다.
- `AttackCombo`에서 각 `EnableHitbox` 순서마다 `Local Euler`와 `Mirror X`를 직접 지정해 다단 공격의 수평 베기·역방향·내려찍기를 독립 조절할 수 있게 했다.
- 3배 확대에서 흐려진 역할별 시트를 셀 `256×256 → 512×512`, 아틀라스 `1024×768 → 2048×1536`으로 절차 재래스터화했다.
- 최종 임포트는 Uncompressed, Bilinear, Clamp, Mipmap Off이며 실루엣·피벗 오차 1% 안에서 선명도를 회복했다.
- 같은 인스턴스의 `Play → Stop → Play`, Loop Off, 그림자·Collider·Rigidbody·Light 없음과 Console 오류·경고 0건을 검증했다.

### Blender 던전 모듈 편집 준비

## 2026-08-09

### UI 공통 디자인·상호작용

- 프로젝트의 로우폴리 숲과 캠프 분위기에 맞춰 나무 프레임, 어두운 천/양피지 패널, 등급색 포인트를 공통 UI 테마로 정리했다.
- 장비 슬롯을 인벤토리 슬롯과 같은 기준으로 통일하고, 미착용 상태는 실제 장비 이미지가 아니라 투명한 부위 실루엣으로 표시했다.
- 버튼과 슬롯에 포인터를 올리면 살짝 확대되고 벗어나면 돌아오는 피드백을 적용했다.
- 좌표만 확인하지 않고 실제 화면 캡처를 기준으로 프레임·글·이미지·설명창 겹침을 반복 보정했다.

### 캐릭터 관리·기억 구성

- 1920×1080 캐릭터 관리 화면에 인벤토리, 장비 슬롯, 캐릭터 정보, 선택 아이템 상세 정보를 다시 배치했다.
- 인벤토리 장비를 부위 슬롯으로 드래그해 장착하고 장비 슬롯에서 드래그해 해제할 수 있게 했다.
- 인벤토리와 장착 슬롯을 클릭하면 동일한 선택 아이템 정보 창이 갱신되도록 했다.
- 기억 구성은 왼쪽 보유 기억, 오른쪽 위 선택 정보, 오른쪽 아래 장착 기억 슬롯 구조로 개편했다.
- 왼쪽 탭에서 캐릭터 관리와 기억 구성을 오가며 두 화면이 같은 나무 프레임과 여백 규칙을 사용하게 했다.

### 커스터마이징·해금·로컬라이징

- 커스터마이징을 화살표 순환 방식에서 왼쪽 부위 선택·오른쪽 파츠 그리드/색상 선택 방식으로 바꿨다.
- 기본 외형은 장비 미착용으로 시작하며, 왼쪽 카테고리와 오른쪽 그리드가 배경 테두리를 넘거나 메인 화면에 남는 문제를 수정했다.
- 장비 해금 화면에 카테고리, 해금 목록, 선택 장비 정보, 정수 비용과 진행도를 배치했다.
- 한국어/영어 문자열 테이블과 런타임 바인더를 구축하고 현재 화면에서는 한국어와 영어가 섞이지 않게 한국어만 노출했다.

### 메뉴·HUD·지도·사망 흐름

- 일시정지 메뉴의 계속하기·옵션·게임 종료를 한국어로 통일하고 옵션 진입 시 화면이 검게 남는 문제를 수정했다.

- 인게임 HP, 포션, 골드, 정수, 미니맵에 배경과 아이콘을 적용하고 재화 마름모 아이콘 정렬을 보정했다.
- 미니맵과 `M` 전체 지도, Fog of War를 공통 디자인으로 개편했다.
- 화톳불 성장 화면과 사망 결과/장비 유지·미선택 화면을 같은 UI 계열로 정리했다.

- 매 런 약한 시작 단검(공격력 10)을 무료 지급하도록 했다.
- 사망 장비 선택 후보에서 무료 시작 단검과 포션·재료를 제외했다.
- 장비를 선택하지 않고 진행하는 **아무것도 지키지 않기** 경로를 추가했다.
- 사망 후 다음 런에도 보유 기억과 장착 순서를 유지하고 `RewardManager`에서 `PlayerCombat`으로 다시 동기화한다.
- 장비를 들고 있어도 `SmallAttack`만 실행되던 2회차 폴백을 수정했다.
- 공격 중 사망하면 콤보 상태와 무기 그립을 강제로 정리해 ATTACK 상태가 다음 런까지 남지 않게 했다.

### 조작·락온·카메라

- 실제 기능과 다른 Input Action 이름을 정리했다: `Jump`→`Dodge`, `Interection`→`Interaction`, `DrinkPosion`→`DrinkPotion`.
- 락온 키를 Q로 확정했다.
- 락온 중 기억 공격은 가장 가까운 다른 적이 아니라 고정한 대상을 향해 돌진·회전하게 했다.
- 락온 중에도 WASD 입력 방향으로 회피하도록 했다.
- 락온 카메라의 구도를 조정해 대상이 캐릭터 뒤에 가려지는 문제를 완화했다.
- **남은 수정:** 락온 후 좌우·후방 스트레이프의 이동 방향과 애니메이션 블렌드는 아직 수정이 필요하다.

### 포션·적·사운드·드랍 QA

- 포션을 F키 직접 입력과 Input System 이벤트 양쪽에서 사용할 수 있게 했다.
- 포션 애니메이터 상태가 없거나 진입하지 못해도 정해진 시간 뒤 회복이 완료되는 폴백을 추가했다.
- 스켈레톤이 사라졌다 나타나거나 몬스터가 바닥에 잠기는 애니메이션/루트 위치 문제를 수정했다.
- 몬스터 무기 트레일과 실제 칼날/히트박스가 어긋나는 경로를 정리했다.
- 몬스터 발소리를 3D 위치·이동 상태에 맞추고 비활성/사망 후 잔류음을 점검했다.
- 일반 몬스터와 네임드 처치 시 장비·포션·정수 드랍 경로를 점검했다.

### 아레나 개발 도구

- F2/F3 패널이 열려 있을 때 카메라 Look 입력을 차단하고 커서를 해제했다.

### 장비 드랍 표현

- 장비 드랍은 2D 아이콘을 숨기고 실제 3D 모델을 표시한다.
- 무기 모델은 눕히지 않고 세워서 지면보다 약 1.2m 위에 배치한다.
- 픽업 루트와 등급 VFX는 지면에 고정하고 무기 모델만 부유·회전한다.
- 일반/레어는 등급색 라이트, 에픽은 보라색 원형 마법진, 유니크는 노란색 광기둥, 레전더리는 하늘색 광기둥을 사용한다.
- 유니크·레전더리 기둥에 바닥 원, 코어, 수직 streak, mote, 회전 나선 레이어를 추가했다.
- 빔을 지면에 닿게 내리고 투명도를 낮췄으며 `VFXEasyMakerAura`를 제거해 무기가 가려지지 않게 했다.

### 무기 파지·방향

- `WeaponData`에 `GripPosition`과 `GripEuler`를 추가했다.
- 무기 기본 그립과 기억별 `_GripEuler`를 쿼터니언으로 합성한다.
- 프리팹 루트 전체를 보정해 메시·히트박스·트레일이 같은 기준을 사용한다.
- 물리 무기 15종의 손잡이 위치를 조정했다.
- `GSOneHand_T1`, `GSGreat_T3`, `GoldSword`의 칼날 방향을 Z 180도로 보정했다.
- 황금 장식검은 손잡이 끝을 잡던 위치를 `GripPosition.z = -0.08`로 옮겼다.
