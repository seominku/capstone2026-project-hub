- 음용 완료/중단 시 포션 모델과 코루틴·Drink 상태를 정리하도록 보완했다.
- Cinemachine 충돌 함수 비교에서 포션 보정이 2.404m에서 0m로 줄었고 벽 충돌은 유지됐다. 실제 정지 음용 중 카메라 거리 4.238m 유지, 포션 1개 소모와 모델 정리 확인. 테스트 소모량/위치를 복원하고 편집 모드로 복귀했다.

### 락온 스트레이프 이동·애니메이션

- 이동 축을 캐릭터의 직전 회전이 아닌 락온 대상 방향으로 계산한다. W는 접근, S는 후진, A/D는 대상 주위 접선 방향 이동이다.
- 좌우·앞뒤 상태 사이를 대각선 입력마다 반복 전환하던 구조를 대기·전진·후진·좌우 5개 클립의 단일 2D 블렌드 트리로 교체했다.
- 실제 이동을 캐릭터 로컬 방향으로 변환해 모션과 일치시키고, 대각선 속도를 제한하면서 아날로그 입력 강도를 보존한다.
- 반대 방향 회피 후에도 수평 회전으로 대상을 다시 바라본다. UI/공격/회피로 이동이 차단되거나 락온·컴포넌트가 해제되면 잔류 이동 블렌드를 초기화한다.
- 검증: 실제 Player 프리팹으로 8방향·정지·약한 입력 및 90/180/270도 회전 복귀 검사 통과. 프리뷰 이미지 확인. 정상 시작 메뉴/난이도 선택 이후 플레이 모드에서 횡이동·후진·대각선·UI 차단·락온 해제 재생값 확인.
