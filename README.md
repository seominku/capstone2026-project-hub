# 잠들지 않는 숲 · ROOTBOUND
C0D3X의 3D 액션 로그라이트를 소개하는 정적 웹사이트입니다.

- 공개 주소: https://seominku.github.io/capstone2026-project-hub/
- 구성: 게임 소개 / 이야기 / 숲과 심층 / 전투와 성장 / 기억 / 장비 / 몬스터 / 다운로드
- 내용 기준: 2026-10-26 실제 프로젝트의 등록 장비·9단계 경로·기억 사본·캠프 준비·폭포 복귀를 대조했습니다.
- Windows0.3.20261026 설치 파일과 휴대용 ZIP은 GitHub Releases에서 배포합니다. 완료되지 않은 파티 모드는 지원 기능으로 소개하지 않습니다.
- `/play/`: 실제 Unity WebGL 싱글 플레이. Web 전용 번역 예열 뒤 기존12씬/9단계 캠페인을 실행합니다. PC 키보드/마우스·WebGL2 필요, 초기 다운로드 약343MiB, 브라우저별 IndexedDB 저장(Windows와 분리), 일부 물 표현은 기존 대체 수면 경로입니다. 모바일 터치/파티 지원으로 표시하지 않습니다.

## 로컬 실행
이 폴더에서 `python -m http.server 4173 --bind 127.0.0.1` 실행 후 http://127.0.0.1:4173/ 을 여세요.
별도 패키지 설치나 빌드 과정이 없는 HTML/CSS/JavaScript입니다.

## 유지 관리
- `index.html`: 페이지 구획, 메타 정보, 탐색과 도감 UI
- `styles.css`: 밝은 종이색/숲색 디자인 및 반응형 화면
- `showcase.css`: 인게임 이미지 중심의 큰 타이틀, 영상/갤러리·다운로드와 등급 테두리
- `app.js`: 해시 탐색, 필터/검색/페이지 이동, 이미지 확대
- `data.js`: 방문자용 스토리·여정·전투 설명
- `catalog-data.js`: 실제 등록 에셋 기준 무기54 / 방어구300 / 반지7 / 기억22종
- `equipment-options.js`: 현행 Unity 솔로 규칙에서 추출한 부위/등급별 감정 범위330행·깊은 밤 각인35개·레전더리 고유 효과4개. 기존 저장 옵션에는 새 범위를 소급 적용하지 않음
- `assets/equipment-v03/`: 원본 스프라이트 영역의 해상도·비율을 보존한 장비 아이콘361개. 작은 원본을 확대하거나 정사각형으로 늘리지 않고, 미리보기에서도 실제 픽셀 크기를 넘기지 않음
- `assets/current/`: 이전 웹용256px 아이콘 보존본. 현재 장비 화면은 위의 원본 비율 이미지를 사용함
- `assets/media/`: 67.3초 v05 소개 영상/함께 제공하는 음원 출처. 촬영 연출·후반 믹스이며 연속 실전 완주 영상이 아님
- `assets/download/checksums.txt`: 공개 설치 파일/ZIP의 SHA-256
- `assets/game/`: 실제 게임 캡처의 리사이즈·웹 인코딩본. 보스 연출 촬영과 미로 관찰 화면은 실제 플레이 HUD 캡처와 구별합니다.
- `assets/memories/`: 실제 적용 중인 무게별 v02 기억 아이콘
- 장비 수치는 감정·품질·성장에 따라 바뀌므로 원본 템플릿의 공격력/체력을 고정 성능처럼 노출하지 않습니다.
- 기억은 등급 없이 무게별로 표시합니다. 방어구/무기 등급 표기는 실제 게임의 일반·레어·에픽·유니크·레전더리를 따릅니다.
- 페이지 이동은 기존 즐겨찾기의 일부 해시를 새 메뉴로 연결합니다. 이전 관리 메뉴 주소는 소개 화면으로 보냅니다.

## 사이트 성격 변경
개발 현황·로드맵·QA·피드백 및 내부 문서/Figma 링크를 방문자 화면에서 제거했습니다.
과거 `story-data.js`, `systems-data.js`, `asset-swap-data.js`, `docs/`, `pdf/`는 기록 보존용이며 현재 화면에서 로드하거나 링크하지 않습니다. 예전 브라우저의 피드백 저장소도 삭제하지 않습니다.
공개 저장소에 남은 기록의 완전 삭제/공개 범위 변경은 이번 개편의 범위가 아닙니다.

## 배포
기존 GitHub Pages 설정인 `main` 브랜치 루트에서 배포됩니다. 승인된 소개 콘텐츠/영상/아이콘 및 검수한 실제 Web Player만 커밋합니다. Unity 프로젝트 소스·개인 저장은 업로드하지 않으며 설치 EXE와 ZIP은 Releases 자산으로 올립니다. Web 데이터/코드는 각각48MiB 이하의 해시 이름 파일로 나누고 매 파일 SHA256/크기 검증 후 공식 Unity 로더로 실행합니다. 임의 콘텐츠로 게임을 흉내 낸 페이지가 아닙니다. `autoSyncPersistentDataPath`로 브라우저 저장을 유지하며 기존 종료 버튼은 저장 flush 완료 후 소개 화면으로 복귀합니다.

Web 검수는 기존 시작·실제 키보드 이동/ESC·새로고침 저장·9단계 진행과 일반 URL의 마차/메뉴/옵션/종료를 확인합니다. 진행 자동 검수는 기존 출구/거래 콜백을 호출하는 fixture이며 자연 보행 완주/전투 승률/전시드·모든 브라우저/16.7ms 검수가 아닙니다. Web 빌드 전용 opt-in QA는 명시적 `webqa` query에서만 별도 저장 폴더를 쓰며 일반 접속에는 생성되지 않습니다.

0.3 웹 화면 검수: 데스크톱1440/모바일390, 탐색8개/도감·등급·부위 필터/아이콘 원본 크기/감정8부위×5등급·각인35개/실제 영상 재생 등87검사 통과, JS/네트워크 오류0. 설치본은 별도 경로에만 설치해208개 게임 파일 SHA 및26개 시작 검사/제거를 통과했습니다. 세부 원시는 Unity 프로젝트의 Docs/QA/ReleaseRefresh_20261026에 보관하며 방문자 화면에는 개발 현황·QA·로드맵·피드백을 표시하지 않습니다.

0.3 Web 파일은 `play/releases/0.3.20261026/`의 새 해시 경로에서 제공하며 이전 Web 파일은 보존합니다. `play/build-manifest.json`이 활성 버전·각 파일 SHA를 지정합니다.
