# 잠들지 않는 숲 · ROOTBOUND
C0D3X의 3D 액션 로그라이트를 소개하는 정적 웹사이트입니다.

- 공개 주소: https://seominku.github.io/capstone2026-project-hub/
- 구성: 게임 소개 / 이야기 / 숲과 심층 / 전투와 성장 / 기억 / 장비 / 몬스터
- 내용 기준: 2026-09-28 프로젝트 구현과 스토리 원문을 대조했습니다. 제작 중인 게임이므로 수치·화면은 바뀔 수 있습니다.
- 설치 파일은 배포하지 않습니다. 완료되지 않은 파티 모드를 지원 기능으로 소개하지 않습니다.

## 로컬 실행
이 폴더에서 `python -m http.server 4173 --bind 127.0.0.1` 실행 후 http://127.0.0.1:4173/ 을 여세요.
별도 패키지 설치나 빌드 과정이 없는 HTML/CSS/JavaScript입니다.

## 유지 관리
- `index.html`: 페이지 구획, 메타 정보, 탐색과 도감 UI
- `styles.css`: 밝은 종이색/숲색 디자인 및 반응형 화면
- `app.js`: 해시 탐색, 필터/검색/페이지 이동, 이미지 확대
- `data.js`: 방문자용 스토리·여정·전투 설명
- `catalog-data.js`: 실제 에셋 기준 무기 15 / 방어구 300 / 반지 2 / 기억 22종
- `assets/game/`: 실제 게임 캡처의 리사이즈·웹 인코딩본. 보스 연출 촬영과 미로 관찰 화면은 실제 플레이 HUD 캡처와 구별합니다.
- `assets/memories/`: 실제 적용 중인 무게별 v02 기억 아이콘
- 장비 수치는 감정·품질·성장에 따라 바뀌므로 원본 템플릿의 공격력/체력을 고정 성능처럼 노출하지 않습니다.
- 기억은 등급 없이 무게별로 표시합니다. 방어구/무기 등급 표기는 실제 게임의 일반·레어·에픽·유니크·레전더리를 따릅니다.
- 페이지 이동은 기존 즐겨찾기의 일부 해시를 새 메뉴로 연결합니다. 이전 관리 메뉴 주소는 소개 화면으로 보냅니다.

## 사이트 성격 변경
개발 현황·로드맵·QA·피드백 및 내부 문서/Figma 링크를 방문자 화면에서 제거했습니다.
과거 `story-data.js`, `systems-data.js`, `asset-swap-data.js`, `docs/`, `pdf/`는 기록 보존용이며 현재 화면에서 로드하거나 링크하지 않습니다. 예전 브라우저의 피드백 저장소도 삭제하지 않습니다.
공개 저장소에 남은 기록의 완전 삭제/공개 범위 변경은 이번 개편의 범위가 아닙니다.

## 배포
기존 GitHub Pages 설정인 `main` 브랜치 루트에서 배포됩니다. 이 저장소에 승인된 소개 콘텐츠만 커밋·푸시하며 Unity 프로젝트, 개인 저장, 설치 파일은 추가하지 않습니다.
